КАПСУЛА — многостраничный демонстрационный сайт

Файлы:
index.html — главная
about.html — о барбершопе
services.html — услуги
team.html — мастера
contacts.html — контакты
style.css — общий дизайн
script.js — мобильное меню
assets/ — папка для будущих фото

Для публикации на GitHub Pages загрузите ВСЕ файлы и папку assets в корень репозитория. Не загружайте только index.html.
Все пункты меню ведут на отдельные HTML-страницы. Онлайн-запись открывает указанную ссылку YCLIENTS.
Адрес, официальный прайс и информация о мастерах пока обозначены как данные для уточнения.
Фотографии демонстрационные, загружаются из Unsplash через интернет; для финальной версии замените их фото барбершопа.
