КАПСУЛА — демонстрационный сайт барбершопа

В архиве:
- index.html — главная страница
- style.css — дизайн и адаптация под телефон
- script.js — мобильное меню
- assets/ — резервная папка для фотографий, которые можно добавить позже

Как открыть:
1. Распакуйте ZIP.
2. Откройте index.html в браузере.

Как опубликовать через GitHub Pages:
1. Загрузите ВСЕ файлы и папку assets в корень репозитория.
2. В Settings -> Pages выберите Deploy from a branch, ветка main, папка /(root).
3. Сохраните настройки.

Ссылки записи ведут на YCLIENTS, телефон и почта кликабельны.
Пока нет точного адреса, реального прайса и данных мастеров — на сайте это честно отмечено как информация для добавления.
Фото в демо загружаются с Unsplash через интернет; для финальной версии лучше заменить их на фотографии самого барбершопа.
